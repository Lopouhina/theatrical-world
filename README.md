## Описание проекта

«Театральный мир» — многостраничный сайт-каталог театральных постановок, предназначенный для поиска и подбора спектаклей.

Проект разрабатывается в рамках дисциплины «Фронтенд и бэкенд разработка».

## Страницы сайта

1. Главная — популярные спектакли, новинки и рекомендации.
2. Каталог спектаклей — поиск, фильтрация и сортировка.
3. Жанры — драмы, комедии, мюзиклы, балет и опера.
4. Актёры — биографии и список постановок.
5. Страница спектакля — описание, фотографии, актёрский состав и отзывы.
6. Избранное — сохранённые спектакли.
7. Отзывы — оценки и рецензии зрителей.

## Технологии
- HTML
- CSS
- JavaScript

## Планируемый функционал

- Поиск спектаклей по названию.
- Фильтрация по жанру, продолжительности, возрастному ограничению, стране и рейтингу.
- Сортировка по популярности, рейтингу и дате премьеры.
- Добавление отзывов и оценок.
- Добавление спектаклей в избранное.
- Выбор случайного спектакля.
- Рекомендации по настроению и предпочтениям.

## Используемые технологии

- HTML5 — семантическая структура страниц.
- CSS3 — оформление интерфейса.
- Flexbox — навигация и выравнивание элементов.
- CSS Grid — сетка карточек спектаклей.
- БЭМ — методология именования CSS-классов.
- CSS-переменные — единая система оформления.
- JavaScript — планируемая интерактивность.
- Git и GitHub — контроль версий.
