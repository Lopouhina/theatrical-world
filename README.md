# Театральный мир

Сайт-каталог театральных постановок для поиска и подбора спектаклей.

## Технологии
- HTML
- CSS
- JavaScript

## Возможности
- Каталог спектаклей
- Поиск и фильтрация
- Сортировка спектаклей
- Информация об актёрах
- Отзывы и оценки
- Избранное
- Генератор случайного спектакля
- Подбор спектаклей по настроению
